📊 Personal Finance Tracker & Expense Analytics
This project is a Business Intelligence (BI) tool designed for personal financial management. The core objective is to transform a standard expense spreadsheet into a strategic dashboard that identifies financial bottlenecks and maximizes savings capacity.

🎯 Project Goals
The system is designed to be simple yet efficient. It allows for detailed expense tracking and clear visualization of unnecessary spending, empowering the user to make smarter, data-driven decisions about their money.

🛠️ Tech Stack
SQL (MySQL): Used for data extraction, joining multiple sources (Union), and comprehensive data cleansing.

Power BI: Used for creating interactive visualizations and advanced DAX measures.

Excel/CSV: Serves as the primary data source, allowing for dynamic and easy updates.

💡 Key Features
Data Consolidation: Merges different expense sources into a single "Fact Table" via SQL.

Smart Classification: Automatically categorizes transactions into Fixed vs. Variable costs.

"Small Leak" Analysis: Identifies recurring minor expenses that silently drain the monthly budget.

Seasonality Trends: Visualizes spending peaks by day of the week and month.

Scenario Simulation: Dynamic DAX measures to compare real-time spending against user-inputted income.
