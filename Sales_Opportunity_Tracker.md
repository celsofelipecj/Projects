## 📊 Project Overview
This project is a comprehensive BI solution for a B2B industrial hardware company. It transforms raw CRM data into actionable insights to monitor revenue, sales funnel efficiency, and team performance.

## 📸 Dashboard Preview
## 🛠️ Tech Stack
* **SQL (MySQL):** Data cleaning (handling "NODATA" & string inconsistencies) and creating optimized Views for analysis.
* **Power BI:** Data modeling using Star Schema and interactive report design.
* **DAX:** Custom measures for Time Intelligence (Month-over-Month) and sales conversion KPIs.

## 🧠 Key Business Questions Answered
* Which industry sectors generate the highest revenue?
* What is the sales conversion rate (Win Rate) per manager?
* Which products are overperforming or underperforming by region?
* Are there significant gaps between MSRP (Sales Price) and final Close Value?
