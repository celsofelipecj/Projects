📊 Overview (healthcare_performance_analytics)

This project analyzes hospital encounter data to monitor financial health. It identifies which medical procedures are profitable and how well insurance providers (Payers) cover hospital costs.

🛠️ Tech Stack
Database: MySQL (Data modeling and Views).

BI Tool: Power BI (DAX and Interactive Dashboards).

💡 Key Business Questions
Profitability: Which departments (Urgent Care, Outpatient) generate the most net profit?

Payer Efficiency: Does insurance coverage ($) meet the actual cost of the procedure?

Trends: How is revenue evolving month-over-month?

🚀 How I Built It
SQL ETL: Cleaned and transformed raw hospital data into a "Business View" to simplify analysis.

Data Modeling: Created a Star Schema in Power BI for efficient filtering.

Financial KPIs: Developed DAX measures for Total Revenue, Net Profit, and Reimbursement Rate (%).

📈 Key Insights
Identified specific procedures where hospital costs exceeded insurance payouts.

Mapped the "Payer Mix" to see which insurance companies represent the bulk of the revenue.

Automated the monthly reporting process using a dynamic Calendar table.
